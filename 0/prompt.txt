#  Dungeon Lighting Themes
the expanding lighting vocabulary much more deliberately.

## Good candidates:
Crypt rooms: candles/embers, low radius, soft warm pools.
Hydraulics rooms: cold blue-green pulses near vents/plinths.
Spider rooms: biolum mushrooms/web motes, dim green-blue breathing light.
Shrine rooms: holy pulse for good shrines, void/occult absorption for cursed/dark shrines.
Armory rooms: metal glints from weapon racks, sharper low-radius highlights.
Kitchen rooms: cooking fire plus ember floor warmth.
Some of this can be done with existing feature identities and collectLightSources. 

For richer authored behavior, I’d add a component like:
LightEmitter {
  radius,
  color,
  pattern,
  softness,
  kind,          // normal | void (this may not be needed with a null voidStrength)
  voidStrength, // honestly anything other than null should imply void
}

Then room generation can place lighting intent as data instead of adding more kind === ... checks in display code.
